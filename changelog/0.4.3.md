# 0.4.3 — Production-ready Kubernetes deploys, chat attachments, and Vertex AI

**Released:** May 16, 2026 · **Channel:** Stable · **Tag:** [`v0.4.3`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/v0.4.3)

The first patch series on 0.4.x, with roughly 90 merged PRs. Self-hosters get a production-grade Helm chart for Kubernetes, chat picks up file attachments (PDF, JPG, PNG) from the UI and Slack, and the model layer adds Google Vertex AI plus an Exa web-search engine. A new PipesHub CLI and a round of OpenAPI-spec cleanup make the platform easier to script against, alongside a broad set of connector, agent, and UI fixes.

## Highlights

### Production-ready Kubernetes deployment

A new Helm chart delivers a production-shaped Kubernetes deploy — StatefulSets for the stateful backends, horizontal pod autoscaling, and a local Kind-based development flow ([#2179](https://github.com/pipeshub-ai/pipeshub-ai/pull/2179) — @anupPradhan0). Docker builds also got faster ([#2275](https://github.com/pipeshub-ai/pipeshub-ai/pull/2275) — @abhishekgml1991).

### Chat attachments and richer model support

Conversations now accept PDF, JPG, and PNG attachments, both from the platform UI and from Slack ([#2190](https://github.com/pipeshub-ai/pipeshub-ai/pull/2190) — @kaushal1999). On the model side, Google Vertex AI is supported ([#2279](https://github.com/pipeshub-ai/pipeshub-ai/pull/2279) — @abhishekgml1991), Exa joins as a web-search engine ([#2241](https://github.com/pipeshub-ai/pipeshub-ai/pull/2241)), and Gemini/Whisper and Azure OpenAI configuration issues were fixed ([#2245](https://github.com/pipeshub-ai/pipeshub-ai/pull/2245), [#2201](https://github.com/pipeshub-ai/pipeshub-ai/pull/2201) — @vanshg685).

### A CLI and an SDK-ready API surface

A new PipesHub CLI handles environment setup and configuration ([#1772](https://github.com/pipeshub-ai/pipeshub-ai/pull/1772) — @Kushagra1122). The search and conversation APIs were made SDK-ready ([#2267](https://github.com/pipeshub-ai/pipeshub-ai/pull/2267) — @uncleSlayer), with the OpenAPI spec cleaned up to match reality: broken or non-streaming endpoints removed ([#2282](https://github.com/pipeshub-ai/pipeshub-ai/pull/2282), [#2283](https://github.com/pipeshub-ai/pipeshub-ai/pull/2283), [#2287](https://github.com/pipeshub-ai/pipeshub-ai/pull/2287)) and knowledge-hub, knowledge-search, and model-listing specs fixed ([#2265](https://github.com/pipeshub-ai/pipeshub-ai/pull/2265), [#2286](https://github.com/pipeshub-ai/pipeshub-ai/pull/2286), [#2262](https://github.com/pipeshub-ai/pipeshub-ai/pull/2262)).
