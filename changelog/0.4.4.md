# 0.4.4 — Jira and Confluence Data Center connectors

**Released:** May 18, 2026 · **Channel:** Stable · **Tag:** [`v0.4.4`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/v0.4.4)

A quick patch release (~20 PRs) whose main story is on-prem Atlassian: new connectors for Confluence Data Center and Jira Data Center bring self-hosted Atlassian instances into PipesHub search, alongside a Docker image size reduction and a batch of rendering and filter fixes.

## Highlights

### Atlassian Data Center support

Organizations running self-hosted Atlassian can now index their content: a Confluence Data Center connector ([#2302](https://github.com/pipeshub-ai/pipeshub-ai/pull/2302) — @shrikantNemiwal1) and a Jira Data Center connector ([#2303](https://github.com/pipeshub-ai/pipeshub-ai/pull/2303) — @darshangodase), with a follow-up fix so Jira ticket titles reach the indexing pipeline ([#2323](https://github.com/pipeshub-ai/pipeshub-ai/pull/2323)).

### Smaller Docker images

The Docker image was optimized to cut size and build time ([#2304](https://github.com/pipeshub-ai/pipeshub-ai/pull/2304) — @abhishekgml1991) — continued in 0.4.5's slim image work.

## Connectors

- Local filesystem records expose a `localFsRelativePath` in file-record and service response types ([#2311](https://github.com/pipeshub-ai/pipeshub-ai/pull/2311) — @Kushagra1122).
- Filters removed after a connector instance is created are now pruned ([#2324](https://github.com/pipeshub-ai/pipeshub-ai/pull/2324) — @abhishekgml1991); non-default datetime filters no longer get selected on their own ([#2317](https://github.com/pipeshub-ai/pipeshub-ai/pull/2317) — @shrikantNemiwal1).

## Agents & AI

- Removing a tool from an agent is now handled cleanly ([#2309](https://github.com/pipeshub-ai/pipeshub-ai/pull/2309) — @jatingaur18).
- Agent-builder node height no longer balloons with large system prompts ([#2310](https://github.com/pipeshub-ai/pipeshub-ai/pull/2310) — @vishwjeet-pawar03).

## Fixes

- Document handling: PPTX format detection ([#2305](https://github.com/pipeshub-ai/pipeshub-ai/pull/2305) — @kaushal1999) and Mermaid diagram rendering ([#2316](https://github.com/pipeshub-ai/pipeshub-ai/pull/2316) — @vishwjeet-pawar03).
- Chat UI: image display overflow ([#2307](https://github.com/pipeshub-ai/pipeshub-ai/pull/2307)) and a "show more" control on citations ([#2308](https://github.com/pipeshub-ai/pipeshub-ai/pull/2308) — @vishwjeet-pawar03).
- Forgot-password now displays errors ([#2315](https://github.com/pipeshub-ai/pipeshub-ai/pull/2315) — @vanshg685).

## Developer experience & infrastructure

- Electron CI added for the desktop app ([#2312](https://github.com/pipeshub-ai/pipeshub-ai/pull/2312) — @realaashil).
- Dependency bumps ([#2296](https://github.com/pipeshub-ai/pipeshub-ai/pull/2296), [#2263](https://github.com/pipeshub-ai/pipeshub-ai/pull/2263), [#2319](https://github.com/pipeshub-ai/pipeshub-ai/pull/2319)), with the tar bump reverted ([#2322](https://github.com/pipeshub-ai/pipeshub-ai/pull/2322) — @abhishek-pipeshub).
