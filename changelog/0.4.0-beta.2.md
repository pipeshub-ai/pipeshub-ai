# 0.4.0-beta.2 — Next.js frontend previews; GitLab, Salesforce, and Zoom connectors arrive

**Released:** May 2, 2026 · **Channel:** Beta · **Tag:** [`v0.4.0-beta.2`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/v0.4.0-beta.2)

*This beta was finalized as [0.4.0](0.4.0.md).*

The pre-release cut of the 0.4.0 cycle — 350+ merged PRs since 0.3.0. It previews the new Next.js frontend (the legacy React UI still ships in this beta; it was removed in the stable release), adds GitLab, Salesforce, Zoom, and personal Outlook connectors, brings web search, a coding sandbox with artifacts, and image/speech model support to the assistant, and expands toolsets with Redshift, OneDrive, Zoom, and Salesforce. Operators gain Redis as an optional message broker, Windows support, Python 3.12, and hot-reloading dev composes. See the [0.4.0 changelog](0.4.0.md) for the finalized release including the last round of fixes.

## Breaking changes & upgrade notes

- Python services moved to Python 3.12 ([#1755](https://github.com/pipeshub-ai/pipeshub-ai/pull/1755)).
- The frontend consolidates on a single backend URL; redundant URL settings were removed ([#1780](https://github.com/pipeshub-ai/pipeshub-ai/pull/1780)).
- Unnecessary container ports are no longer exposed, alongside a logs cleanup ([#1890](https://github.com/pipeshub-ai/pipeshub-ai/pull/1890)).

## Highlights

### Next.js frontend preview

The React SPA was rewritten as a Next.js application ([#1882](https://github.com/pipeshub-ai/pipeshub-ai/pull/1882) — @abhishek-pipeshub), shipping alongside the legacy UI in this beta with its own build workflow ([#1920](https://github.com/pipeshub-ai/pipeshub-ai/pull/1920)), Turbopack in dev mode ([#1937](https://github.com/pipeshub-ai/pipeshub-ai/pull/1937) — @akshay-pythm), and a broad cleanup pass ([#1970](https://github.com/pipeshub-ai/pipeshub-ai/pull/1970)). Much of this beta's fix volume is polish on the new UI.

### Coding sandbox, artifacts, and image generation

Conversations can run code in a sandbox and produce artifacts, backed by a new image-generation model type ([#2031](https://github.com/pipeshub-ai/pipeshub-ai/pull/2031) — @abhishekgml1991), with follow-ups for local executor errors ([#2048](https://github.com/pipeshub-ai/pipeshub-ai/pull/2048)), artifact UI issues ([#2050](https://github.com/pipeshub-ai/pipeshub-ai/pull/2050)), PPTX-as-PDF rendering with debounced SSE updates ([#2053](https://github.com/pipeshub-ai/pipeshub-ai/pull/2053)), and a longer image-generation timeout ([#2072](https://github.com/pipeshub-ai/pipeshub-ai/pull/2072) — @abhishek-pipeshub). Speech-to-text and text-to-speech model types were added alongside ([#2033](https://github.com/pipeshub-ai/pipeshub-ai/pull/2033)).

### New connectors: GitLab, Salesforce, Zoom, personal Outlook

GitLab connector v1 syncs work items and merge requests (with notes) plus project code files ([#1857](https://github.com/pipeshub-ai/pipeshub-ai/pull/1857) — @jain-ayush-wyld). Salesforce arrives as a connector ([#1787](https://github.com/pipeshub-ai/pipeshub-ai/pull/1787)) and toolset ([#1862](https://github.com/pipeshub-ai/pipeshub-ai/pull/1862) — @jatingaur18). Zoom gets a connector ([#1809](https://github.com/pipeshub-ai/pipeshub-ai/pull/1809) — @darshangodase) and toolset ([#1687](https://github.com/pipeshub-ai/pipeshub-ai/pull/1687) — @jatingaur18) with meeting web/recording URLs and transcript highlighting ([#1819](https://github.com/pipeshub-ai/pipeshub-ai/pull/1819), [#1820](https://github.com/pipeshub-ai/pipeshub-ai/pull/1820), [#1752](https://github.com/pipeshub-ai/pipeshub-ai/pull/1752)). A personal Outlook connector rounds out the set ([#1756](https://github.com/pipeshub-ai/pipeshub-ai/pull/1756) — @shrikantNemiwal1).

### Toolsets become first-class

Dedicated toolset pages ([#1954](https://github.com/pipeshub-ai/pipeshub-ai/pull/1954) — @vishwjeet-pawar03) with documentation links ([#1997](https://github.com/pipeshub-ai/pipeshub-ai/pull/1997)), new Redshift ([#1686](https://github.com/pipeshub-ai/pipeshub-ai/pull/1686) — @Ayushman444) and OneDrive ([#1926](https://github.com/pipeshub-ai/pipeshub-ai/pull/1926) — @jatingaur18) toolsets, API-token auth for Jira and Confluence ([#1742](https://github.com/pipeshub-ai/pipeshub-ai/pull/1742) — @darshangodase), a developer-settings page for OAuth 2.0 apps ([#1913](https://github.com/pipeshub-ai/pipeshub-ai/pull/1913) — @vanshg685), and OAuth apps visible to non-admins ([#2138](https://github.com/pipeshub-ai/pipeshub-ai/pull/2138) — @realaashil).

### Web search and deeper agent modes

The assistant gains web search ([#1903](https://github.com/pipeshub-ai/pipeshub-ai/pull/1903) — @kaushal1999), wired into the agent schema and builder UI ([#2125](https://github.com/pipeshub-ai/pipeshub-ai/pull/2125), [#2143](https://github.com/pipeshub-ai/pipeshub-ai/pull/2143), [#2147](https://github.com/pipeshub-ai/pipeshub-ai/pull/2147)), plus an agent mode ([#1874](https://github.com/pipeshub-ai/pipeshub-ai/pull/1874) — @tushar1245). The deep agent adds a critic + reflector loop ([#1739](https://github.com/pipeshub-ai/pipeshub-ai/pull/1739) — @Ayushman444), and the universal agent picks up tools ([#2100](https://github.com/pipeshub-ai/pipeshub-ai/pull/2100), [#2059](https://github.com/pipeshub-ai/pipeshub-ai/pull/2059) — @vishwjeet-pawar03).

### Indexing reconciliation, SQL connectors, and deployment flexibility

The indexing pipeline gains reconciliation alongside SQL connectors ([#1568](https://github.com/pipeshub-ai/pipeshub-ai/pull/1568) — @Ayushman444), with indexing performance improved in two rounds ([#1692](https://github.com/pipeshub-ai/pipeshub-ai/pull/1692) — @mstcomit, [#1759](https://github.com/pipeshub-ai/pipeshub-ai/pull/1759) — @kaushal1999) and Docling worker tuning ([#1773](https://github.com/pipeshub-ai/pipeshub-ai/pull/1773)). Redis can stand in for Kafka as the message broker ([#1823](https://github.com/pipeshub-ai/pipeshub-ai/pull/1823) — @realaashil), Windows is supported ([#1844](https://github.com/pipeshub-ai/pipeshub-ai/pull/1844), [#1833](https://github.com/pipeshub-ai/pipeshub-ai/pull/1833)), dev composes hot-reload ([#1746](https://github.com/pipeshub-ai/pipeshub-ai/pull/1746) — @anupPradhan0, [#1782](https://github.com/pipeshub-ai/pipeshub-ai/pull/1782)), Neo4j/Mongo DB names are env-configurable ([#1743](https://github.com/pipeshub-ai/pipeshub-ai/pull/1743) — @tushar1245), Docker logs rotate ([#1747](https://github.com/pipeshub-ai/pipeshub-ai/pull/1747)), and `--wait` blocks until healthy ([#2024](https://github.com/pipeshub-ai/pipeshub-ai/pull/2024)).
