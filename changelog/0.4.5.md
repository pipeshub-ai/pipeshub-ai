# 0.4.5 — GitLab self-managed (EE) support and slimmer deployments

**Released:** May 20, 2026 · **Channel:** Stable · **Tag:** [`v0.4.5`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/v0.4.5)

A ~20-PR patch release focused on self-hosted GitLab: the GitLab connector now works against self-managed EE instances. Deployment gets lighter with a slimmer Docker image and simplified port/URL configuration, and sign-in becomes more flexible with support for multiple authentication mechanisms per org.

## Highlights

### GitLab self-managed (EE) support

The GitLab connector now supports self-managed Enterprise Edition instances ([#2337](https://github.com/pipeshub-ai/pipeshub-ai/pull/2337) — @abhishekgml1991), with instance-URL fixes ([#2350](https://github.com/pipeshub-ai/pipeshub-ai/pull/2350)) and an AQL lock-timeout fix during GitLab sync ([#2340](https://github.com/pipeshub-ai/pipeshub-ai/pull/2340) — @tushar1245).

### Slimmer, simpler deployment

The Docker image was slimmed down ([#2325](https://github.com/pipeshub-ai/pipeshub-ai/pull/2325) — @abhishekgml1991), and networking was simplified: port 3001 is exposed directly and the separate connector public URL is gone ([#2326](https://github.com/pipeshub-ai/pipeshub-ai/pull/2326)).

### More flexible authentication

Orgs can enable multiple authentication mechanisms side by side ([#2341](https://github.com/pipeshub-ai/pipeshub-ai/pull/2341) — @vanshg685), and SAML just-in-time provisioning was fixed ([#2345](https://github.com/pipeshub-ai/pipeshub-ai/pull/2345)).

## Connectors

- OneDrive toolset fix ([#2224](https://github.com/pipeshub-ai/pipeshub-ai/pull/2224) — @jatingaur18).
- Arango cleanup on connector-instance deletion fixed ([#2344](https://github.com/pipeshub-ai/pipeshub-ai/pull/2344) — @shrikantNemiwal1).
- Scheduled crawling functionality (and its tests) removed from connectors ([#2333](https://github.com/pipeshub-ai/pipeshub-ai/pull/2333) — @Kushagra1122).

## Agents & AI

- Deep agent no longer drags previous conversations into a new one ([#2332](https://github.com/pipeshub-ai/pipeshub-ai/pull/2332) — @vishwjeet-pawar03).
- Model selection for agents fixed ([#2336](https://github.com/pipeshub-ai/pipeshub-ai/pull/2336)) and agents now show a creator tag ([#2331](https://github.com/pipeshub-ai/pipeshub-ai/pull/2331) — @vishwjeet-pawar03).

## Fixes

- File preview moved to a split-screen layout ([#2339](https://github.com/pipeshub-ai/pipeshub-ai/pull/2339) — @vishwjeet-pawar03), recent chats are collapsible ([#2328](https://github.com/pipeshub-ai/pipeshub-ai/pull/2328)), and a workspace overflow issue was fixed ([#2343](https://github.com/pipeshub-ai/pipeshub-ai/pull/2343)).
- User-group rename API is only called when the name actually changed ([#2330](https://github.com/pipeshub-ai/pipeshub-ai/pull/2330) — @realaashil).
- A missing method was restored ([#2347](https://github.com/pipeshub-ai/pipeshub-ai/pull/2347) — @abhishek-pipeshub).

## Performance & reliability

- Redis consumers drop unparsable messages completely instead of retrying them forever ([#2335](https://github.com/pipeshub-ai/pipeshub-ai/pull/2335) — @realaashil).
- GitHub star count is cached instead of fetched per request ([#2348](https://github.com/pipeshub-ai/pipeshub-ai/pull/2348) — @abhishekgml1991).

## Developer experience & infrastructure

- Electron CI follow-up ([#2329](https://github.com/pipeshub-ai/pipeshub-ai/pull/2329) — @realaashil).
