# 0.1.1-alpha — BookStack and ServiceNow connectors arrive, SAML gets JIT provisioning

**Released:** November 5, 2025 · **Channel:** Alpha · **Tag:** [`v0.1.1-alpha`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/v0.1.1-alpha)

*This alpha line was finalized as [0.1.0](0.1.0.md).*

A week after the founding [0.1.0-alpha](0.1.0-alpha.md), this release adds two new full connectors — BookStack and ServiceNow Knowledge Base — improves SAML sign-in with just-in-time user provisioning, and lands a broad stabilization pass across indexing, the agent pipeline, and the frontend (27 merged PRs).

## Highlights

### BookStack connector

A new connector for the BookStack wiki platform, bringing self-hosted documentation into PipesHub search ([#887](https://github.com/pipeshub-ai/pipeshub-ai/pull/887) — @R0gue-one), with a follow-up patch for record web URLs ([#960](https://github.com/pipeshub-ai/pipeshub-ai/pull/960)).

### ServiceNow Knowledge Base connector

ServiceNow KB articles can now be synced and searched ([#894](https://github.com/pipeshub-ai/pipeshub-ai/pull/894) — @shrikantNemiwal1).

### SAML just-in-time provisioning

SAML authentication now provisions users on first sign-in instead of requiring a pre-existing account ([#959](https://github.com/pipeshub-ai/pipeshub-ai/pull/959) — @GauravAhuja7, first contribution), with a follow-up fix ([#969](https://github.com/pipeshub-ai/pipeshub-ai/pull/969) — @abhishekgml1991).

### Agent pipeline and LLM health checks

The agent execution pipeline was updated ([#931](https://github.com/pipeshub-ai/pipeshub-ai/pull/931) — @vishwjeet-pawar03), and model configuration now runs a modality-aware LLM health check so misconfigured vision/text models are caught up front ([#947](https://github.com/pipeshub-ai/pipeshub-ai/pull/947) — @kaushal1999).

## Connectors

- **Web** — fixed HTML image handling in the web connector ([#932](https://github.com/pipeshub-ai/pipeshub-ai/pull/932) — @kaushal1999).
- **Gmail** — fixed a local-assignment bug in the Gmail change handler ([#938](https://github.com/pipeshub-ai/pipeshub-ai/pull/938) — @vishwjeet-pawar03) and image handling in mail indexing ([#939](https://github.com/pipeshub-ai/pipeshub-ai/pull/939) — @kaushal1999).
- **Outlook** — fixed next-link handling and pagination during sync ([#957](https://github.com/pipeshub-ai/pipeshub-ai/pull/957) — @shrikantNemiwal1).
- Removed redundant OAuth scopes from connector configuration ([#945](https://github.com/pipeshub-ai/pipeshub-ai/pull/945) — @vishwjeet-pawar03) and added guards for connectors with no auth type set ([#940](https://github.com/pipeshub-ai/pipeshub-ai/pull/940)).
- Fixed scheduled-sync deletion and filtered folders out of record listings ([#948](https://github.com/pipeshub-ai/pipeshub-ai/pull/948) — @R0gue-one).

## Agents & AI

- Plain-text files are now converted to blocks for indexing ([#953](https://github.com/pipeshub-ai/pipeshub-ai/pull/953) — @kaushal1999).
- Fixed the token counter for tool calls ([#951](https://github.com/pipeshub-ai/pipeshub-ai/pull/951) — @kaushal1999) and a query bug in `build_group_text` ([#965](https://github.com/pipeshub-ai/pipeshub-ai/pull/965)).
