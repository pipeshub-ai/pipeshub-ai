# 0.1.0 — First stable release: security hardening and connector filters mature

**Released:** December 23, 2025 · **Channel:** Stable · **Tag:** [`0.1.0`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/0.1.0)

PipesHub's first stable release finalizes the [0.1.0-beta](0.1.0-beta.md) and the alpha series before it ([0.1.0-alpha](0.1.0-alpha.md) → [0.1.1-alpha](0.1.1-alpha.md) → [0.1.2-alpha](0.1.2-alpha.md)). The 23 merged PRs on top of the beta concentrate on production readiness: a security hardening pass across the Node.js API (configurable JWT expiry, stack traces stripped from responses, stricter validation middleware), connector filters extended to Outlook and Confluence with manual sync, SharePoint page support, and Google Slides/Docs/Sheets moved onto the unified blocks parsing pipeline.

## Highlights

### Security hardening for production

JWT expiry moved to an environment variable ([#1153](https://github.com/pipeshub-ai/pipeshub-ai/pull/1153) — @tushar1245, first contribution), stack traces removed from API responses ([#1155](https://github.com/pipeshub-ai/pipeshub-ai/pull/1155) — @tushar1245), email added to validation middleware ([#1157](https://github.com/pipeshub-ai/pipeshub-ai/pull/1157) — @vishwjeet-pawar03), and two further batches of security fixes ([#1152](https://github.com/pipeshub-ai/pipeshub-ai/pull/1152) — @vishwjeet-pawar03, [#1154](https://github.com/pipeshub-ai/pipeshub-ai/pull/1154) — @tushar1245).

### Connector filters mature

The filter system introduced in the beta now covers Outlook and Confluence ([#1122](https://github.com/pipeshub-ai/pipeshub-ai/pull/1122) — @shrikantNemiwal1) and supports manually triggered filtered syncs ([#1132](https://github.com/pipeshub-ai/pipeshub-ai/pull/1132) — @shrikantNemiwal1).

### SharePoint pages and Google file parsing

The SharePoint connector now indexes SharePoint pages, not just files ([#1129](https://github.com/pipeshub-ai/pipeshub-ai/pull/1129) — @R0gue-one), and Google Slides, Docs, and Sheets are converted through the unified blocks pipeline for higher-fidelity chunking and citations ([#1130](https://github.com/pipeshub-ai/pipeshub-ai/pull/1130) — @jain-ayush-wyld).

## Agents & AI

- Fixed a metadata-enhancement bug in the query pipeline ([#1081](https://github.com/pipeshub-ai/pipeshub-ai/pull/1081) — @kaushal1999) and a bug in OpenAI-compatible embeddings ([#1125](https://github.com/pipeshub-ai/pipeshub-ai/pull/1125)).
- Multiple citations inside a single bracket pair are now handled ([#1124](https://github.com/pipeshub-ai/pipeshub-ai/pull/1124) — @kaushal1999), and the reflection retry count was raised to 2 ([#1128](https://github.com/pipeshub-ai/pipeshub-ai/pull/1128)).
