# 0.3.0 — Agents get toolsets and MCP, Slack becomes a real bot platform, Neo4j joins as a graph option

**Released:** March 20, 2026 · **Channel:** Stable · **Tag:** [`v0.3.0`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/v0.3.0)

0.3.0 spans 150+ merged PRs and is squarely an AI-platform release. Agents gain configurable toolsets — Jira, ClickUp, MariaDB, Microsoft Teams, Outlook, and GitHub — plus a new deep-agent mode, and PipesHub ships an MCP server bundled with the main service so external AI clients can talk to your workspace over the OAuth2 stack that matured this release (RFC 9728 metadata, dedicated frontend pages, admin developer settings). The Slack bot grows up too: streamed answers, multiple bots per deployment, and multi-user conversations per thread with @mention resolution.

For operators, Neo4j lands as an alternative graph database alongside ArangoDB (including optional Helm support), the web connector gets a substantial reliability overhaul, and CI gains an integration-test workflow, an OpenAPI validator, and broader lint enforcement. New datasource clients arrive for RSS, ClickHouse, Lattice, Databricks, Lumos, ClickUp, and a personal GitHub connector.

## Breaking changes & upgrade notes

- Deprecated endpoints were removed from the OpenAPI spec ([#1582](https://github.com/pipeshub-ai/pipeshub-ai/pull/1582), [#1597](https://github.com/pipeshub-ai/pipeshub-ai/pull/1597)); the signed-URL download route was removed everywhere in favor of authenticated downloads ([#1470](https://github.com/pipeshub-ai/pipeshub-ai/pull/1470)).
- The `connector_disabled` and `paused` indexing statuses were removed from records ([#1663](https://github.com/pipeshub-ai/pipeshub-ai/pull/1663)); connectors configured for manual sync no longer sync on service startup ([#1592](https://github.com/pipeshub-ai/pipeshub-ai/pull/1592)).
- The KV migration is skipped when etcd is not set up ([#1562](https://github.com/pipeshub-ai/pipeshub-ai/pull/1562)).

## Highlights

### Agent toolsets and a deep agent

Agents can now be equipped with toolsets ([#1506](https://github.com/pipeshub-ai/pipeshub-ai/pull/1506), multi-toolset support [#1579](https://github.com/pipeshub-ai/pipeshub-ai/pull/1579) — @vishwjeet-pawar03), and a deep-agent mode arrives together with Microsoft Teams, Outlook, and GitHub toolsets ([#1642](https://github.com/pipeshub-ai/pipeshub-ai/pull/1642)). The catalog grows with a ClickUp toolset ([#1688](https://github.com/pipeshub-ai/pipeshub-ai/pull/1688), merge fix [#1719](https://github.com/pipeshub-ai/pipeshub-ai/pull/1719) — @darshangodase) and a MariaDB toolset with conversation tasks ([#1674](https://github.com/pipeshub-ai/pipeshub-ai/pull/1674) — @Ayushman444). Agents also became aware of their own capabilities ([#1670](https://github.com/pipeshub-ai/pipeshub-ai/pull/1670)), gained per-agent instructions in the frontend ([#1554](https://github.com/pipeshub-ai/pipeshub-ai/pull/1554)), and were promoted to the navbar as a beta ([#1520](https://github.com/pipeshub-ai/pipeshub-ai/pull/1520)). Follow-up fixes covered the Jira toolset ([#1596](https://github.com/pipeshub-ai/pipeshub-ai/pull/1596)), deep-agent retrieval ([#1652](https://github.com/pipeshub-ai/pipeshub-ai/pull/1652)), toolset instance deletion ([#1624](https://github.com/pipeshub-ai/pipeshub-ai/pull/1624)), the toolset config dialog ([#1644](https://github.com/pipeshub-ai/pipeshub-ai/pull/1644)), removal of the toolset migration ([#1657](https://github.com/pipeshub-ai/pipeshub-ai/pull/1657)), and stale agent-chat state ([#1659](https://github.com/pipeshub-ai/pipeshub-ai/pull/1659)).

### MCP integration on a maturing OAuth2 stack

An MCP server is now bundled with the main service ([#1611](https://github.com/pipeshub-ai/pipeshub-ai/pull/1611), fix [#1633](https://github.com/pipeshub-ai/pipeshub-ai/pull/1633) — @realaashil), letting MCP-capable AI clients connect to PipesHub. Supporting it, the OAuth2 stack matured substantially: an OAuth Protected Resource Metadata endpoint per RFC 9728 ([#1607](https://github.com/pipeshub-ai/pipeshub-ai/pull/1607)), Cursor custom-URI support ([#1608](https://github.com/pipeshub-ai/pipeshub-ai/pull/1608)), OAuth2 frontend pages ([#1542](https://github.com/pipeshub-ai/pipeshub-ai/pull/1542)), an admin-only developer-settings section ([#1553](https://github.com/pipeshub-ai/pipeshub-ai/pull/1553)), confirmation dialogs for deleting OAuth apps or revoking tokens ([#1547](https://github.com/pipeshub-ai/pipeshub-ai/pull/1547)), redirect required only for the authorization-code grant ([#1598](https://github.com/pipeshub-ai/pipeshub-ai/pull/1598)), auth-middleware handling ([#1509](https://github.com/pipeshub-ai/pipeshub-ai/pull/1509) — @rish664), and a series of OAuth and scope fixes ([#1507](https://github.com/pipeshub-ai/pipeshub-ai/pull/1507), [#1544](https://github.com/pipeshub-ai/pipeshub-ai/pull/1544), [#1617](https://github.com/pipeshub-ai/pipeshub-ai/pull/1617)).

### Slack bot: streaming, multi-bot, multi-user threads

The Slack bot switched to the chat stream API for real-time answers ([#1526](https://github.com/pipeshub-ai/pipeshub-ai/pull/1526) — @kaushal1999), supports multiple bots per deployment ([#1538](https://github.com/pipeshub-ai/pipeshub-ai/pull/1538)), and handles multi-user conversations per thread with @mention resolution ([#1593](https://github.com/pipeshub-ai/pipeshub-ai/pull/1593)). Slack events are now proxied through the Node.js API ([#1531](https://github.com/pipeshub-ai/pipeshub-ai/pull/1531) — @abhishekgml1991). Formatting and robustness fixes cover newline rendering ([#1566](https://github.com/pipeshub-ai/pipeshub-ai/pull/1566)), table streaming and per-message character limits ([#1573](https://github.com/pipeshub-ai/pipeshub-ai/pull/1573)), email and HTML entities ([#1601](https://github.com/pipeshub-ai/pipeshub-ai/pull/1601)), @mention stripping from queries ([#1529](https://github.com/pipeshub-ai/pipeshub-ai/pull/1529)), startup without a configured bot ([#1634](https://github.com/pipeshub-ai/pipeshub-ai/pull/1634)), permission management ([#1552](https://github.com/pipeshub-ai/pipeshub-ai/pull/1552)), and general bot fixes ([#1625](https://github.com/pipeshub-ai/pipeshub-ai/pull/1625)).

### Neo4j as an alternative graph database

Neo4j support was merged as a graph-database option alongside ArangoDB ([#1427](https://github.com/pipeshub-ai/pipeshub-ai/pull/1427) — @tushar1245), with linting integration ([#1577](https://github.com/pipeshub-ai/pipeshub-ai/pull/1577)), corrected setup instructions ([#1606](https://github.com/pipeshub-ai/pipeshub-ai/pull/1606)), a KB-sharing-status query fix ([#1701](https://github.com/pipeshub-ai/pipeshub-ai/pull/1701)), and optional Neo4j support in the Helm chart ([#1696](https://github.com/pipeshub-ai/pipeshub-ai/pull/1696) — @anupPradhan0).

### Web connector overhaul

The web connector got a sustained reliability push from @R0gue-one: a generator-based crawl function ([#1539](https://github.com/pipeshub-ai/pipeshub-ai/pull/1539)), retry mechanism ([#1551](https://github.com/pipeshub-ai/pipeshub-ai/pull/1551)), crawl scoped to stay within the start URL with domain checks at processing time ([#1641](https://github.com/pipeshub-ai/pipeshub-ai/pull/1641), [#1650](https://github.com/pipeshub-ai/pipeshub-ai/pull/1650)), connector filters ([#1556](https://github.com/pipeshub-ai/pipeshub-ai/pull/1556)), content and metadata processing ([#1570](https://github.com/pipeshub-ai/pipeshub-ai/pull/1570)), improved HTML cleaning ([#1618](https://github.com/pipeshub-ai/pipeshub-ai/pull/1618)), AVIF processing and better SVG handling ([#1541](https://github.com/pipeshub-ai/pipeshub-ai/pull/1541)), parent-child relations ([#1643](https://github.com/pipeshub-ai/pipeshub-ai/pull/1643)), a settings revert back to sync settings ([#1587](https://github.com/pipeshub-ai/pipeshub-ai/pull/1587)), and rounds of bug fixes ([#1610](https://github.com/pipeshub-ai/pipeshub-ai/pull/1610), [#1658](https://github.com/pipeshub-ai/pipeshub-ai/pull/1658), crawl fixes [#1527](https://github.com/pipeshub-ai/pipeshub-ai/pull/1527) — @realaashil).

New sources this cycle: an RSS connector ([#1475](https://github.com/pipeshub-ai/pipeshub-ai/pull/1475) — @uncleSlayer), ClickHouse with org APIs ([#1488](https://github.com/pipeshub-ai/pipeshub-ai/pull/1488), [#1498](https://github.com/pipeshub-ai/pipeshub-ai/pull/1498) — @uncleSlayer), Lattice ([#1545](https://github.com/pipeshub-ai/pipeshub-ai/pull/1545) — @rish664), Databricks ([#1638](https://github.com/pipeshub-ai/pipeshub-ai/pull/1638)), Lumos ([#1640](https://github.com/pipeshub-ai/pipeshub-ai/pull/1640)), ClickUp ([#1683](https://github.com/pipeshub-ai/pipeshub-ai/pull/1683)), and a GitHub personal connector ([#1469](https://github.com/pipeshub-ai/pipeshub-ai/pull/1469) — @jain-ayush-wyld).
