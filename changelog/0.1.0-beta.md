# 0.1.0-beta — Connector filters, five new data sources, and a security hardening sweep

**Released:** December 9, 2025 · **Channel:** Beta · **Tag:** [`0.1.0-beta`](https://github.com/pipeshub-ai/pipeshub-ai/releases/tag/0.1.0-beta)

*This beta was finalized as [0.1.0](0.1.0.md).*

The first beta after the [alpha series](0.1.2-alpha.md) focuses on controlling what gets synced and broadening where data comes from: connector filters let operators scope which content a connector ingests, and Dropbox, NextCloud, Trello, Bitbucket, and Workday all gain data sources. A long run of dependency security fixes, an MD5-based file version control scheme, and a fix for HTTP connections dying after a day push the platform toward stable (40 merged PRs).

## Highlights

### Connector filters

Connectors can now be configured with filters that scope which content is synced, with an Autocomplete-based management UI and improved types ([#1058](https://github.com/pipeshub-ai/pipeshub-ai/pull/1058) — @shrikantNemiwal1, [#1083](https://github.com/pipeshub-ai/pipeshub-ai/pull/1083) — @vishwjeet-pawar03).

### Five new data sources

Community contributions widen the connector fleet: a Dropbox individual connector ([#1067](https://github.com/pipeshub-ai/pipeshub-ai/pull/1067) — @SharmaNishchay, first contribution), NextCloud ([#1090](https://github.com/pipeshub-ai/pipeshub-ai/pull/1090) — @SharmaNishchay), Trello ([#1001](https://github.com/pipeshub-ai/pipeshub-ai/pull/1001) — @gunnuh, first contribution), Bitbucket ([#1118](https://github.com/pipeshub-ai/pipeshub-ai/pull/1118) — @uncleSlayer), and Workday via code generation ([#1114](https://github.com/pipeshub-ai/pipeshub-ai/pull/1114), [#1117](https://github.com/pipeshub-ai/pipeshub-ai/pull/1117) — @PhantomInTheWire, first contribution; generator fixes and cleanup in [#1119](https://github.com/pipeshub-ai/pipeshub-ai/pull/1119), [#1120](https://github.com/pipeshub-ai/pipeshub-ai/pull/1120) — @rish664).

### MD5 checksum file version control

Files are now versioned by MD5 checksum, so unchanged files can be detected and skipped instead of re-processed ([#1091](https://github.com/pipeshub-ai/pipeshub-ai/pull/1091) — @anirudh7371, first contribution).

### Team management UI

Organizations get a team management interface in the frontend ([#1095](https://github.com/pipeshub-ai/pipeshub-ai/pull/1095) — @vishwjeet-pawar03).

### Opik LLM observability

Opik integration adds tracing/observability for LLM calls in the query pipeline ([#1093](https://github.com/pipeshub-ai/pipeshub-ai/pull/1093) — @kaushal1999).

- **Connectors** — connectors can be configured with filters that scope which content is synced, with an Autocomplete-based management UI ([#1058](https://github.com/pipeshub-ai/pipeshub-ai/pull/1058) — @shrikantNemiwal1, [#1083](https://github.com/pipeshub-ai/pipeshub-ai/pull/1083) — @vishwjeet-pawar03). - **Connectors** — five new data sources: Dropbox individual, NextCloud, Trello, Bitbucket and Workday ([#1067](https://github.com/pipeshub-ai/pipeshub-ai/pull/1067) — @SharmaNishchay, [#1001](https://github.com/pipeshub-ai/pipeshub-ai/pull/1001) — @gunnuh, [#1114](https://github.com/pipeshub-ai/pipeshub-ai/pull/1114) — @PhantomInTheWire). See [the highlight](#five-new-data-sources).
- **Admin & settings** — organizations get a team management interface in the frontend ([#1095](https://github.com/pipeshub-ai/pipeshub-ai/pull/1095) — @vishwjeet-pawar03). See [the highlight](#team-management-ui).
- **Observability** — Opik integration adds tracing for LLM calls in the query pipeline ([#1093](https://github.com/pipeshub-ai/pipeshub-ai/pull/1093) — @kaushal1999). See [the highlight](#opik-llm-observability).
- **Indexing** — Added GIF and SVG image support ([#1077](https://github.com/pipeshub-ai/pipeshub-ai/pull/1077) — @vishwjeet-pawar03).

## Improvements

- **Confluence connector** — permission changes are now synced using the audit log ([#1063](https://github.com/pipeshub-ai/pipeshub-ai/pull/1063) — @shrikantNemiwal1).
- **Models** — Token counting switched to the `cl100k_base` tokenizer ([#1085](https://github.com/pipeshub-ai/pipeshub-ai/pull/1085) — @kaushal1999).
- **Models** — Bedrock: max output tokens raised to 16K for Anthropic models ([#1075](https://github.com/pipeshub-ai/pipeshub-ai/pull/1075) — @kaushal1999); Claude 4.5 models get a 64K max token length ([#1089](https://github.com/pipeshub-ai/pipeshub-ai/pull/1089)).

## Security fixes

- **Dependencies** — A sustained dependency-security sweep: multiple rounds of security fixes and version pins ([#1105](https://github.com/pipeshub-ai/pipeshub-ai/pull/1105), [#1106](https://github.com/pipeshub-ai/pipeshub-ai/pull/1106), [#1107](https://github.com/pipeshub-ai/pipeshub-ai/pull/1107), [#1109](https://github.com/pipeshub-ai/pipeshub-ai/pull/1109), [#1112](https://github.com/pipeshub-ai/pipeshub-ai/pull/1112), [#1108](https://github.com/pipeshub-ai/pipeshub-ai/pull/1108) — @abhishekgml1991) plus Dependabot batches and lock-file updates ([#1100](https://github.com/pipeshub-ai/pipeshub-ai/pull/1100), [#1102](https://github.com/pipeshub-ai/pipeshub-ai/pull/1102), [#1104](https://github.com/pipeshub-ai/pipeshub-ai/pull/1104)).

## Performance & reliability

- **Indexing** — files are versioned by MD5 checksum, so unchanged files are detected and skipped instead of re-processed ([#1091](https://github.com/pipeshub-ai/pipeshub-ai/pull/1091) — @anirudh7371). See [the highlight](#md5-checksum-file-version-control).
- **API** — Fixed HTTP connections breaking after roughly a day of uptime ([#1099](https://github.com/pipeshub-ai/pipeshub-ai/pull/1099) — @abhishekgml1991).
- **API** — Increased a timeout ([#1074](https://github.com/pipeshub-ai/pipeshub-ai/pull/1074)).
- **Deployment** — Services now start their processes in a defined order ([#1121](https://github.com/pipeshub-ai/pipeshub-ai/pull/1121) — @abhishekgml1991).
