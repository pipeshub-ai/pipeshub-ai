# Autonomous Action Rules

1. **Git Commit Approval**: Always wait for the user's explicit approval before running `git commit` and `git push`. Never commit code autonomously without being explicitly instructed to do so by the user.

2. **Answering Questions**: When the user asks a question, do NOT start working autonomously on your own. Always ask for their explicit permission before beginning any work, planning, or execution in response to a question.
